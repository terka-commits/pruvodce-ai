# Průvodce AI

Prototyp pro soutěž **AI výzva pro Česko**. Portál, který firmám pomáhá zavést AI tak, aby se jí kolegové nebáli. Rozlišuje pohled vedení a ambasadora a nabízí rozcestník pro konkrétní firmu.

**Online verze:** https://claude.ai/artifact/SqpJzUoqNrTPcd8g54EhAV

## Jak otevřít

Dvojklikem na `index.html` (doporučuji Chrome nebo Safari). Jde o jeden statický soubor bez buildu. Internet je potřeba jen pro písma a odkazy na nástroje. Data se ukládají pouze v prohlížeči. Pro ukázku klikněte na **Otevřít ukázkovou firmu**.

## Obsah repozitáře

| Soubor | Popis |
| --- | --- |
| `index.html` | Hotová stránka, otevřít dvojklikem |
| `pruvodce-zdroj.html` | Stejný obsah ve verzi pro Claude artefakt (tak je publikovaný online) |
| `prepis-session.md` | Textový přepis celé konverzace při tvorbě (Markdown) |
| `PRECTI-ME.txt` | Stručný návod k otevření |

## Poznámka

V lokální verzi nefungují AI návrhy, místo nich se zobrazí šablony. Plně fungují jen v publikovaném artefaktu na claude.ai.
